# catherd 2.0, plan 31: the panel, copied from remora; the TUI removed — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the terminal dashboard is deleted, and `catherd panel` serves remora's web console, copied with its design, stack and conventions: Setup (backends with their doctor status, each role's rungs picked from indexed Slopalytics pairs), Runs (the list and each run's live timeline) and Questions (each parked unit with an answer box), on `127.0.0.1` only, behind a random token accepted on the copied login page.

**Architecture:** `web/` is its own Bun package, a copy of `47vigen/remora` `web/` at 17b59b5 with remora's pages replaced by catherd's; it builds to `web/dist`, which `prepack` builds and the tarball ships. `src/entry/panel/openapi.ts` holds one table of operations (method, path, zod query, body, response) that both writes `web/openapi.json` and parses requests in `src/entry/panel/server.ts`: one `Bun.serve` for the built files, the JSON API and a WebSocket per run tailing `events.jsonl`. Reads go through plan 30's `run-read.ts`, answers and cancels through `run-client.ts`, Setup through a new `src/services/panel-setup.ts` over plan 29's `catalogQuery` and doctor's `backendChecks`/`indexCheck`; every write through `ProfilePort.set`.

**Tech Stack:** catherd: Bun ≥ 1.4, TypeScript, zod 4 (`z.toJSONSchema` over a registry), citty. Panel, as remora's `web/package.json` with its version ranges: Vite 8, React 19, HeroUI v3 + `@heroui/styles`, Tailwind v4, TanStack Router (file routes, committed `routeTree.gen.ts`) and Query, `@hey-api/openapi-ts` 0.99.0, Geist fonts, `@gravity-ui/icons`, shiki, `react-aria-components`, oxlint/oxfmt, Vitest + jsdom, Playwright, `vite-plugin-compression2`. Leaving the root: `@opentui/*`, `react`, `@types/react`.

**Spec:** `docs/specs/2026-10-12-catherd-2.0-design.md`, decisions 15, 23–26. Source (read-only): `/Users/vigen/agora/lab/remora/web` at 17b59b5, remora's `THIRD_PARTY_NOTICES.md` and `LICENSE`.

**Pre-validation: spiked a zod 4 registry through `z.toJSONSchema(reg, { uri })` into an OpenAPI 3.1 document that `@hey-api/openapi-ts` 0.99.0 (remora's installed copy) turned into `listRunsOptions`, `answerUnitMutation` and a `RunView` type with its `$ref`s resolved; `[test] root = "test"` keeping `bun test` out of `web/src`; `bun pm pack` running `prepack` and packing `web/dist` from `files`; targeted tests only; the full gate runs at execution.** Written against `main` at 2061e6e; plans 29, 30 and 30b merge first: re-find every hunk by context.

## Review Focus

1. **Another site, or a DNS-rebound name, calls the panel or opens its socket.** Expected: a `Host` not `127.0.0.1:<port>`/`localhost:<port>` gets 403 first; a write or upgrade from another `Origin` gets 403; the cookie is `HttpOnly; SameSite=Strict`. Task 3: "refuses a Host it does not serve, and a write or a socket from another origin".
2. **The panel restarts while a tab is open.** Expected: 401, the page goes to `/login?redirect=…`, the run's socket closes and stays closed. Task 5: "a 401 sends the run page to login and closes its socket".
3. **A run with thousands of events.** Expected: the timeline is paged newest first on the server; a live entry joins page 1 only. Task 3: "returns a run's timeline newest first, paged"; Task 5: "a live entry joins page 1 only, once".
4. **A 1.5 run listed or opened.** Expected: read-only, engine `1.5`; its page says so and asks for no timeline. Task 3: "a 1.5 run's timeline is empty"; Task 5: "a 1.5 run says so and loads no timeline".
5. **One question answered twice (two tabs).** Expected: the second is refused with plan 30's `E_INPUT_INVALID` message under the box, and the list refreshes. Task 3: "…refuses a second answer for the same unit with the error body"; Task 6: "a refused answer shows the reason and refreshes".

## Rulings

1. Ruling: `web/` is a standalone Bun package (own `bun.lock`, no workspace); `files` adds `web/dist`; root `prepack` runs `panel:build` (`cd web && bun install --frozen-lockfile && bun run build`), so `bun pm pack`, `changeset publish` and the beta publish all build it — root installs stay free of Vite and React — every pack needs the registry.

3. Ruling: the token is 32 random bytes base64url (43 chars), new each start, never on disk; the link is `http://127.0.0.1:<port>/login#token=<token>` (a fragment: no request or log carries it); the login page reads it, clears it with `history.replaceState` and submits it; a sign-in sets `catherd_panel=<32 random bytes>; HttpOnly; SameSite=Strict; Path=/`, sessions in memory — "accepted on remora's login page" — a restart signs every tab out.
4.
