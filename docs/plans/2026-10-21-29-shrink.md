# catherd 2.0, plan 29: shrink — Slopalytics catalog, single scale, Grok/agy removed — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** catherd's catalog reads one source, the Slopalytics proxy, and knows one number per model and effort: its intelligence index. Every benchmark sync, score file, calibration, treat-like, stand-in guess and the Artificial Analysis key are deleted; a pair without an index does not exist; routing bars are intelligence percentiles, one per difficulty; a profile that names an unindexed pair is refused, a run pins the index it started on, and the Grok Build and Antigravity backends are removed.

**Architecture:** `src/domain/slopalytics.ts` parses the proxy's answer and keys a model by its Slopalytics family (`slopKey`); `src/infra/slopalytics.ts` fetches it and reads/writes the cache file `<data>/slopalytics.json`; `refreshIndex` in `src/services/catalog-service.ts` keeps it fresh (1 h, last good kept). `src/domain/catalog.ts` builds the `Catalog` from `catalog/models.json` (capabilities, billing, plan weight, backend mapping) and that index; `select.ts`, `failover.ts`, `bars.ts`, `cost.ts` and `profile-rules.ts` rank on `intelligence` alone. A run copies the index into its folder at `run_start`, and `route` reads that copy.

**Tech Stack:** Bun ≥ 1.4, TypeScript, zod 4, citty, `@modelcontextprotocol/sdk`. No new dependency.

**Spec:** `docs/specs/2026-10-12-catherd-2.0-design.md`, decisions 9–14 (the catalog half of 11; plan 33 owns the routing half) and the Grok/agy part of 16. t3herd (read-only, `<the t3herd clone>` at 71cbb6a): `src/catalog.ts` (cache, TTL, last good), `src/models.ts` (`family`, `joinModels`).

**Pre-validation: spiked the proxy parse (zod 4 in Bun) and, against one live fetch (proxy `fetchedAt` 2026-10-13T20:47Z: 699 records, 689 with an intelligence, no duplicate family#effort), the bar pool and the default profile's coverage, targeted tests only; the full gate runs at execution.**

## Review Focus

1. **First run with no network, or a garbage answer.** Expected: nothing throws; doctor's `catalog` row says `not fetched`/`failing`; `profile validate`'s fix is `catherd catalog sync`; `run_start` refuses naming the roles. Pinned in Task 2 ("records the error, with no index, when the first fetch fails"), Task 3 ("says to sync when there is no index at all"), Task 6 ("refuses to start, creating no run, when a role has no usable rung").
2. **Slopalytics drops a pair a run uses, overnight.** Expected: the run routes on its pinned index. Pinned in Task 6 ("routes a run on its pinned index after the machine's index lost the pair").
3. **A 1.5 profile naming `grok:`/`antigravity:` rungs or `harness.grok`.** Expected: it reads; validate names the rung; `profile set roles.<role>.rungs` replaces it; the billing and harness keys are ignored. Pinned in Task 1 ("reads a stored profile with a Grok rung and harness, and validate names the rung").
4. **A `#default` rung, a dotted or prefixed id (`gpt-6.1-sol`, `opencode-go/kimi-k3`).** Expected: each finds its family; `#default` takes the `default` record, else the only one. Pinned in Task 3 ("maps #default …") and Task 2 ("keys a model as Slopalytics names its family").
5. **`objective: speed` with pairs that have no speed.** Expected: the fastest clearing pair with a speed starts; one without starts only when none with one clears, and is still climbed onto. Pinned in Task 3 ("under speed, starts on the fastest clearing pair that has a speed …").

## Rulings

`Ruling: <what> — <why> — <cost if wrong>`:

1. **Ruling: a bar is `percentile(pool, BAR_PERCENTILE[d])` (copy 25, build 50, logic 60, hard 75, from 1.2); the pool is every indexed pair of a models.json family** — the spec names no pool; all 689 records put hard at 24.6, the shipped families give 33.9 / 40.3 / 42.4 / 47.1 (2026-10-13) and do not move with a machine's listings — the default worker starts copy on Sol medium (Luna high 32.9) and clears no hard bar. **Owner question 1.**
2. **Ruling: a model is keyed by `slopKey` (drop `<provider>/`, lower case, `.` → `-`) of its family id, else of its own id; `claude-haiku-4-5` → `claude-4-5-haiku` and `gemini-3-1-pro` → `gemini-3-1-pro-preview` are renamed; no alias table** — decision 13 makes models.json the mapping; 18 of 20 families already match — those two families' run evidence starts afresh.
3. **Ruling: Cursor "by name" is the same rule (its family when models.json maps the slug, else the slug); the `composer-2-5` family is deleted** — the slug is the listed name — a slug unlike its family (`claude-opus-5-5-thinking`) is absent until models.json maps it.
4. **Ruling: `#default` is the family's `default` record, else its only record, else none; other efforts match by name (Codex `ultra` has none)** — t3herd's `none` fallback reads a reasoning model as non-reasoning — a bare model Slopalytics files under another effort is absent at `#default`.
5. **Ruling: a record is a pair only with a positive finite `intelligence`; `deprecated` and `estimated` records stay** — 10 records have none; deprecation is not in the spec — a deprecated model stays offered.
6. **Ruling: price is the proxy's `inputPrice`/`outputPrice` (null unless both); cached input costs a tenth of the input price; unpriced is `value: null` in tier 1 (metered, or metered on the Claude plan), else 0; `planWeight` still prices chatgpt-plan** — decision 13 drops prices from models.json; the proxy has no cached price — a model with another cache discount ranks slightly off.
7. **Ruling: speed is the proxy's tokens/s; own-run timings (`measuredSecs`, `Catalog.secs`, `timings`) are deleted; under `objective: "speed"` the start is the fastest clearing pair with a speed, else the first clearing one by cost; the ladder above is unchanged** — decision 11; read so a profile never stops for lack of a speed — a measured fast rung no longer wins.
8. **Ruling: `run_start` copies the index it checked into `<run>/slopalytics.json`, and `route` reads it** — "never midway" needs an index the run cannot lose — a run never sees a pair indexed after it started.
9. **Ruling: an unindexed rung or stand-in is a validation error (a warning with `unindexed: "warning"`, which only doctor passes); the repair rule is unchanged, so a profile that already names one accepts no other save until it is removed** — decision 12 — the owner's first edit after Slopalytics drops a pair is that pair (the fix names it).
10. **Ruling: `INDEX_TTL_MS` = 1 h; automatic refreshes at MCP boot, `init` and `run_start` (skipped under `CATHERD_NO_SYNC=1`), on demand by `catherd catalog sync [--force]` and `catalog_sync` (names kept); a failed fetch keeps the last good index and records the error in the file** — t3herd's TTL and fallback; stable names for plan 30 — none.
11. **Ruling: `provenance.ts` stays, shrunk to intelligence, bar, price, speed, cost, index date and evidence** — routes.jsonl keeps a reason — none.
12. **Ruling: `select`, `candidates`, `defaultDifficulty` drop `kind`; `Kind` stays a lane value and in `RouteAnswer`** — decision 11 — none.
13. **Ruling: `rankStandIns` keeps another quota, indexed, not metered, not native `claude:`, never below the rung; Claude-billed last, then nearest intelligence, cost, name** — decision 6 on one scale; reaching every configured backend is plan 33's — none.
14. **Ruling: `catalog.override.json` is no longer read; MIGRATION says to delete it; a role's own bars are plan 33's** — no hand override — custom bars lapse until plan 33.
15. **Ruling: `catalog_query` loses `scored_only`, `catalog list` `--scored`, `catalog sync` `--unmatched`; `catalog treat-like` is deleted** — all listed pairs are indexed — a script passing them fails.
16. **Ruling: models.json drops `sources`, `price`, `releaseDate`, `predecessor`, `speed` and each backend entry's `efforts`/`context` (`{ id }` only); `schema` stays 1; efforts are the backend listing's when it lists the model, else the index's** — decision 13 — an unlisted backend may be offered an effort it cannot run until it lists.
17. **Ruling: the start check is in `startRun` only, not `startWorkspaceChild`** — plan 30 owns run start — a workspace child can start without a rung.
18. **Ruling: the TUI keeps compiling through a shim (`t` offers nothing, `i` shows the intelligence, `r` one Slopalytics row, staged treat-likes are dropped); its tests of those features are deleted and its snapshots re-recorded** — plan 31 deletes the TUI — none.
19. **Ruling: `init` asks no AA key, so piped answers lose a line; a saved `artificialAnalysisApiKey` stays unread** — decision 9 — a piping script drops one line.
20. **Ruling: the Cursor adapter's foreign-`agent` guard stays; `GROK_HOME` leaves gate-env's reserved names** — the guard covers any `agent` binary — none.
