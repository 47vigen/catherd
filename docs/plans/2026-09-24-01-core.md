# catherd core — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The package skeleton and the parts every later plan stands on: the shared types, paths, the run folder, the Codex and opencode runners that turn one role run into one `RunRecord`, and the heavy-command lock.

**Architecture:** One ESM TypeScript package built by tsup into `dist/cli.js`. Runners spawn the vendor CLI with node's `child_process`, stream its JSON events, and parse them into a `RunRecord`. The run folder lives under the data directory, never in the user's repository. Tests drive the runners through fake `codex` and `opencode` executables that replay recorded events.

**Tech Stack:** Node ≥ 22, TypeScript 5, pnpm 10, tsup, vitest, Biome, Changesets, Husky + commitlint. No runtime dependencies in this plan: `node:child_process`, `node:fs`, `node:crypto` and `node:util` (`parseArgs`) only.

**Spec:** `docs/specs/2026-09-24-catherd-design.md` (§3, §4, §7.1, §9, §12, §14).

## Global Constraints

- Node `>=22`, ESM only (`"type": "module"`), package name `catherd`, binary `catherd`, license MIT.
- The config root is `$XDG_CONFIG_HOME/catherd` (default `~/.config/catherd`). The data root is `$XDG_DATA_HOME/catherd` (default `~/.local/share/catherd`). `CATHERD_HOME=<dir>` overrides both, as `<dir>/config` and `<dir>/data`; tests always set it.
- Nothing is ever written into the user's repository by catherd itself: run data lives in `<data>/<repo-slug>/<run-id>/`.
- A run record's `status` is `failed` only on a `turn.failed` event, or on a non-zero exit with no reply. A Codex `{"type":"error"}` event or an `item.completed` item of type `error` (reconnects, transport fallback) never fails a run.
- Codex always runs as `codex exec --ignore-user-config -m <model> -c model_reasoning_effort=<effort> --json -o <reply> …` with the brief on **stdin**, and with `CODEX_HOME` pointing at catherd's own home (`<data>/codex-home`), which holds only a symlink to the user's `auth.json`.
- Codex resume is `codex exec resume … -c sandbox_mode=<sandbox> <thread> -`: without the `-c`, a resume falls back to read-only.
- The TypeSafe key, or any other secret, never appears in argv, logs or run folders. (Nothing in this plan handles it; later plans must keep this true.)
- Conventional Commits with scopes, e.g. `feat(core): …`. Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- **A Codex run that reconnects mid-stream and then finishes.** Expect `status: "ok"`, not `failed`. Pinned in Task 3 with the real reconnect lines from 2026-09-24.
- **Owned files that were already dirty before the run.** "Changed" must mean changed *by this run*, so a snapshot is taken before and compared after, not read from `git status`. Pinned in Task 4.
- **A reply with no STATUS line, or with it not on the last line.** Expect `replyStatus: null` and no crash. Pinned in Task 4.
- **A lock slot held by a process that died.** It must be reclaimed, not waited on forever. Pinned in Task 8.
- **The MCP server dies mid-run** (the user's session closed). The Codex child must keep running and its record must still be written. Pinned in Task 7.
- **An opencode session that goes quiet** (no events for the idle limit, and not busy on the server). It must be interrupted server-side, then recorded as `timeout`. Pinned in Task 6.

```ts
import { homedir } from "node:os";
import { join } from "node:path";

const home = () => process.env.CATHERD_HOME;

export function configDir(): string {
  const h = home();
  if (h) return join(h, "config");
  return join(process.env.XDG_CONFIG_HOME ?? join(homedir(), ".config"), "catherd");
}

export function dataDir(): string {
  const h = home();
  if (h) return join(h, "data");
  return join(process.env.XDG_DATA_HOME ?? join(homedir(), ".local", "share"), "catherd");
}

export function repoSlug(repoRoot: string): string {
  return repoRoot.replace(/^\/+/, "").replaceAll("/", "-");
}

export function runsRoot(repoRoot: string): string {
  return join(dataDir(), repoSlug(repoRoot));
}
```

```ts
type Command = (argv: string[]) => Promise<number>;

export const commands: Record<string, Command> = {};

async function main(argv: string[]): Promise<number> {
  const [name = "", ...rest] = argv;
  if (name === "--version" || name === "-v") {
    const pkg = JSON.parse(readFileSync(new URL("../package.json", import.meta.url), "utf8"));

  if (!cmd) {
    console.error(`catherd: unknown command "${name}". Commands: ${Object.keys(commands).join(", ")}`);
    return 2;
  }
  return cmd(rest);
}

  main(process.argv.slice(2)).then((code) => process.exit(code));
```

```ts
export function splitRung(rung: RungId): { model: string; effort: string } {
```

```ts
import { appendFileSync, existsSync, mkdirSync, readdirSync, readFileSync, renameSync, writeFileSync } from "node:fs";
import { join } from "node:path";
import { dataDir, runsRoot } from "../paths.js";
import type { RunMeta, RunRecord, StateSnapshot } from "../types.js";

export interface Run {
  dir: string;
  id: string;
  meta: RunMeta;
}

const slug = (s: string) =>
  s.toLowerCase().replace(/[^a-z0-9]+/g, "-").replace(/^-|-$/g, "").slice(0, 40) || "run";

const stamp = (d: Date) => d.toISOString().replace(/[-:]/g, "").replace("T", "-").slice(0, 15);

export function createRun(repo: string, title: string, aLines: string[]): Run {
  const now = new Date();
  const id = `${stamp(now)}-${slug(title)}`;

export function listRuns(): Run[] {
  const root = dataDir();
  if (!existsSync(root)) return [];
  const runs: Run[] = [];
  for (const repo of readdirSync(root, { withFileTypes: true })) {
    if (!repo.isDirectory() || repo.name === "locks" || repo.name === "codex-home") continue;

/** Moves the latest round's out/jsonl/err to <name>.r<k>.* so the new round starts clean. */
export function rotateRound(dir: string, name: string): void {
  const p = rolePaths(dir, name);
  const current = [p.out, p.jsonl, p.err].filter((f) => existsSync(f));
  if (current.length === 0) return;
  let k = 1;
  while (["out", "jsonl", "err"].some((x) => existsSync(join(dir, "roles", `${name}.r${k}.${x}`)))) k++;
  for (const x of ["out", "jsonl", "err"] as const) {
    if (existsSync(p[x])) renameSync(p[x], join(dir, "roles", `${name}.r${k}.${x}`));
  }
}
```

```ts
import type { Tokens } from "../types.js";

export interface CodexParse {
  thread: string | null;
  tokens: Tokens;
  turnFailed: boolean;
  failure: string | null;
  limit: boolean;
  cliTooOld: boolean;
  lastEvent: string | null;
}

const LIMIT = /usage limit|rate limit reached|quota exceeded|try again later/i;
const TOO_OLD = /not supported when using Codex with a ChatGPT account/i;

export function parseCodexEvents(lines: string[]): CodexParse {
  const p: CodexParse = {
    thread: null, tokens: { input: 0, cached: 0, output: 0 }, turnFailed: false, failure: null,
    limit: false, cliTooOld: false, lastEvent: null,
  };
  for (const line of lines) {
    if (!line.trim().startsWith("{")) continue;
    let e: Record<string, any>;
    try {
      e = JSON.parse(line);
    } catch {
      continue;
    }
    p.lastEvent = e.item?.type ? `${e.type}/${e.item.type}` : e.type;
    const msg: string = e.message ?? e.error?.message ?? e.item?.message ?? "";
    if (TOO_OLD.test(msg)) p.cliTooOld = true;
    if (e.type === "thread.started") p.thread = e.thread_id ?? null;
    else if (e.type === "turn.completed" && e.usage) {
      p.tokens.input += e.usage.input_tokens ?? 0;
      p.tokens.cached += e.usage.cached_input_tokens ?? 0;
      p.tokens.output += e.usage.output_tokens ?? 0;
    } else if (e.type === "turn.failed") {
      p.turnFailed = true;
      p.failure = msg || "turn failed";
      if (LIMIT.test(msg)) p.limit = true;
    }
  }
  return p;
}
```

```ts
import { createHash } from "node:crypto";
import { existsSync, readdirSync, readFileSync, statSync } from "node:fs";
import { join, relative } from "node:path";
import type { ReplyStatus } from "../types.js";

const STATUS = /^STATUS:\s*(complete|partial|blocked|refused)\s*(?:—|–|-)\s*(.*)$/;
const SKIP = new Set(["node_modules", ".git", "dist", ".next", "coverage"]);

export function parseReplyStatus(reply: string): { status: ReplyStatus | null; why: string | null } {
  const last = reply.trimEnd().split("\n").at(-1)?.trim() ?? "";
  const m = STATUS.exec(last);
  return m ? { status: m[1] as ReplyStatus, why: (m[2] ?? "").trim() } : { status: null, why: null };
}

function walk(repo: string, rel: string, into: Map<string, string>): void {
  const abs = join(repo, rel);
  if (!existsSync(abs)) {
    into.set(rel, "<absent>");
    return;
  }
  if (statSync(abs).isDirectory()) {
    for (const e of readdirSync(abs, { withFileTypes: true })) {
      if (SKIP.has(e.name)) continue;
      walk(repo, relative(repo, join(abs, e.name)), into);
    }
    return;
  }
  into.set(rel, createHash("sha1").update(readFileSync(abs)).digest("hex"));
}

export function snapshotOwned(repo: string, owned: string[]): Map<string, string> {
  const m = new Map<string, string>();
  for (const o of owned) walk(repo, o, m);
  return m;
}

export function changedSince(repo: string, before: Map<string, string>, owned: string[]): string[] {
  const after = snapshotOwned(repo, owned);
  const changed = new Set<string>();
  for (const [p, h] of after) if (before.get(p) !== h && !(h === "<absent>" && !before.has(p))) changed.add(p);
  for (const [p, h] of before) if (!after.has(p) && h !== "<absent>") changed.add(p);
  return [...changed].sort();
}
```

A file inside an owned directory that is deleted drops out of `after` entirely, so the second loop catches deletions.

```ts
import { spawn } from "node:child_process";
import { closeSync, existsSync, openSync, readFileSync } from "node:fs";

export interface ChildOpts {
  cwd: string;
  env: NodeJS.ProcessEnv;
  /** file to feed on stdin; stdin is /dev/null without it */
  stdinFile?: string;
  stdoutFile: string;
  stderrFile: string;
  /** called with each batch of new stdout lines, every pollMs */
  onLines?: (lines: string[]) => void;
  pollMs?: number;
  /** called every tickMs while the child runs */
  onTick?: () => void;
  tickMs?: number;
  /** called once, right after the child starts */
  onSpawn?: (c: { pid: number; kill: () => void }) => void;
}

export interface ChildResult {
  code: number | null;
  pid: number | null;
  signal: NodeJS.Signals | null;
}

export function readLines(file: string): string[] {
  if (!existsSync(file)) return [];
  return readFileSync(file, "utf8").split("\n").filter((l) => l.trim());
}

/**
 * Starts the child detached, in its own process group, with stdout and stderr opened directly on
 * files: it survives the death of this process, and a later reconcile reads what it wrote.
 */
export function runChild(cmd: string, args: string[], o: ChildOpts): Promise<ChildResult> {
  return new Promise((resolve, reject) => {
    const stdin = o.stdinFile ? openSync(o.stdinFile, "r") : "ignore";
    const out = openSync(o.stdoutFile, "w");
    const err = openSync(o.stderrFile, "w");
    const child = spawn(cmd, args, { cwd: o.cwd, env: o.env, stdio: [stdin, out, err], detached: true });
    for (const fd of [stdin, out, err]) if (typeof fd === "number") closeSync(fd);
    const pid = child.pid ?? null;
    const kill = () => {
      try {
        if (pid) process.kill(-pid, "SIGTERM");
      } catch {
        child.kill("SIGTERM");
      }
    };
    if (pid) o.onSpawn?.({ pid, kill });
    let seen = 0;
    const drain = () => {
      const lines = readLines(o.stdoutFile);
      if (lines.length > seen) {
        o.onLines?.(lines.slice(seen));
        seen = lines.length;
      }
    };
    const poll = o.onLines ? setInterval(drain, o.pollMs ?? 1000) : null;
    const tick = o.onTick ? setInterval(o.onTick, o.tickMs ?? 60_000) : null;
    const stop = () => {
      if (poll) clearInterval(poll);
      if (tick) clearInterval(tick);
    };
    child.on("error", (e) => {
      stop();
      reject(e);
    });
    child.on("exit", (code, signal) => {
      stop();
      if (o.onLines) drain();
      resolve({ code, pid, signal });
    });
  });
}
```

Facts it relies on, verified on 2026-09-22 in `~/.agents/skills/using-opencode/scripts/ocrun.sh`:
- `opencode run --format json -m <provider/model>[#variant] [flags] "<prompt>"` with stdin closed.
- Events are JSON lines. The session id is in `.sessionID` on events; reply text is `{"type":"text","part":{"text":…}}`; a failure is `{"type":"error","error":{"message":…}}`; a tool call is `{"type":"tool_use","part":{"tool":…,"state":{"status":"completed|error",…}}}`.
- A tool error is not a failed run.
- `--agent explore --auto` is read-only mode; `--auto` alone lets a role act without asking; the default agent edits and runs commands.
- Killing the client does not stop the session: `opencode api POST /api/session/<id>/interrupt` does.
- Cost: `opencode api GET /api/session/<id>` → `.data.cost`.
- Busy check: `opencode api GET /api/session/<id>/message` contains `"status":"running"` while a tool runs.
- Resume: `-s <sessionID>`.

Effort mapping: the rung's effort is the opencode model variant (`#<effort>`), except the effort `default`, which means no variant. opencode's JSON stream carries no token usage, so `tokens` stays zero and `costUsd` is the record of spend.

```ts
export function opencodeArgs(o: DispatchOpts, brief: string): string[] {
  const { model, effort } = splitRung(o.rung);
  const spec = effort === "default" ? model : `${model}#${effort}`;
  const sandbox = ROLE_SANDBOX[o.role];
  const mode = sandbox === "read-only" ? ["--agent", "explore", "--auto"] : sandbox === "danger-full-access" ? ["--auto"] : [];
  return ["run", "--format", "json", "-m", spec, ...mode, ...(o.thread ? ["-s", o.thread] : []), brief];
}

const api = (cwd: string, ...a: string[]) => {
  try {
    return execFileSync("opencode", ["api", ...a], { cwd, encoding: "utf8", timeout: 15_000 });
  } catch {
    return "";
  }

function parse(lines: string[]) {
  let session: string | null = null;
  const texts: string[] = [];
  const errors: string[] = [];
  for (const l of lines) {
    let e: Record<string, any>;
    try {
      e = JSON.parse(l);
    } catch {
      continue;
    }
    session ??= e.sessionID ?? null;
    if (e.type === "text" && e.part?.text) texts.push(e.part.text);
    if (e.type === "error") errors.push(e.error?.message ?? "error");
  }
  return { session, texts, errors };
}

export function finalizeOpencode(runDir: string, live: LiveMarker, code: number | null, timedOut = false): RunRecord {
  const p = rolePaths(runDir, live.name);
  const ev = parse(readLines(p.jsonl));
  const session = ev.session ?? live.thread;
  const reply = ev.texts.join("\n");
  writeFileSync(p.out, reply);
  let cost = 0;
  if (session) {
    try {
      cost = Number(JSON.parse(api(live.cwd, "GET", `/api/session/${session}`) || "{}")?.data?.cost ?? 0);
    } catch {
      cost = 0;
    }
  }
  const status: RunStatus = timedOut ? "timeout" : ev.errors.length ? "failed" : code !== 0 && !reply ? "failed" : "ok";
  const rs = parseReplyStatus(reply);
  const record: RunRecord = {
    name: live.name, role: live.role, backend: "opencode", rung: live.rung, thread: session, status,
    startedAt: live.startedAt, secs: Math.round((Date.now() - Date.parse(live.startedAt)) / 1000), pid: live.pid,
    tokens: { input: 0, cached: 0, output: 0 }, costUsd: cost,
    changedOwned: changedSince(live.cwd, new Map(Object.entries(live.before)), live.ownedFiles),
    replyStatus: rs.status, replyWhy: rs.why, threadHeavy: false, images: [],
    error: status === "ok" ? null : timedOut ? "no event within the idle limit and not busy" : (ev.errors.at(-1) ?? `exit ${code}`),
    replyPath: p.out,
  };
  appendRunRecord(runDir, record);
  clearLive(runDir, live.name);
  return record;
}

export async function runOpencode(o: DispatchOpts): Promise<RunRecord> {
  const p = rolePaths(o.runDir, o.name);
  rotateRound(o.runDir, o.name);
  const brief = readFileSync(o.thread ? p.fix : p.brief, "utf8");
  const before = Object.fromEntries(snapshotOwned(o.cwd, o.ownedFiles));
  const startedAt = new Date().toISOString();
  const idleMs = (o.idleSecs ?? 600) * 1000;
  let session: string | null = o.thread ?? null;
  let lastEventAt = Date.now();
  let timedOut = false;
  let kill: (() => void) | null = null;
  let live: LiveMarker | null = null;

  // A quiet session that the server says is not running a tool is stuck: interrupt it server-side
  // (killing the client alone leaves it running and editing files), then stop the client.
  const watchdog = setInterval(() => {
    if (Date.now() - lastEventAt < idleMs) return;
    if (session && /"status":"running"/.test(api(o.cwd, "GET", `/api/session/${session}/message`))) {
      lastEventAt = Date.now();
      return;
    }
    timedOut = true;
    if (session) api(o.cwd, "POST", `/api/session/${session}/interrupt`);
    kill?.();
  }, Math.min(1000, idleMs));

  const res = await runChild("opencode", opencodeArgs(o, brief), {
    cwd: o.cwd,
    env: process.env,
    stdoutFile: p.jsonl,
    stderrFile: p.err,
    pollMs: 250,
    onSpawn: ({ pid, kill: k }) => {
      kill = k;
      live = {
        name: o.name, role: o.role, backend: "opencode", rung: o.rung, pid, thread: o.thread ?? null, startedAt,
        cwd: o.cwd, ownedFiles: o.ownedFiles, before,
      };
      writeLive(o.runDir, live);
    },
    onLines: (lines) => {
      lastEventAt = Date.now();
      session ??= parse(lines).session;
    },
    tickMs: Number(process.env.CATHERD_TICK_MS ?? 60_000),
    onTick: () => o.onProgress?.({ secs: Math.round((Date.now() - Date.parse(startedAt)) / 1000), lastEvent: null }),
  }).finally(() => clearInterval(watchdog));
  if (!live) throw new Error("catherd: opencode did not start");
  return finalizeOpencode(o.runDir, live, res.code, timedOut);
}
```

```ts
import type { RunRecord } from "../types.js";
import { finalizeCodex } from "./codex.js";
import { finalizeOpencode } from "./opencode.js";
import { type LiveMarker, readLive } from "./runstore.js";

export function pidAlive(pid: number): boolean {
  try {
    process.kill(pid, 0);
    return true;
  } catch (e) {
    return (e as NodeJS.ErrnoException).code === "EPERM";
  }
}

export function reconcileLive(runDir: string): { finished: RunRecord[]; stillRunning: LiveMarker[] } {
  const finished: RunRecord[] = [];
  const stillRunning: LiveMarker[] = [];
  for (const m of readLive(runDir)) {
    if (pidAlive(m.pid)) {
      stillRunning.push(m);
      continue;
    }
    finished.push(m.backend === "codex" ? finalizeCodex(runDir, m, null) : finalizeOpencode(runDir, m, null));
  }
  return { finished, stillRunning };
}
```

```ts
import { spawn } from "node:child_process";
import { mkdirSync, openSync, readFileSync, unlinkSync, writeSync, closeSync } from "node:fs";
import { availableParallelism } from "node:os";
import { join } from "node:path";
import { parseArgs } from "node:util";
import { dataDir } from "../paths.js";
import { pidAlive } from "./reconcile.js";

export function heavySlots(setting: number | "cpus/2" | undefined): number {
  if (typeof setting === "number") return Math.max(1, Math.floor(setting));
  return Math.max(1, Math.floor(availableParallelism() / 2));
}


function tryTake(file: string, label: string): boolean {
  try {
    const fd = openSync(file, "wx");
    writeSync(fd, JSON.stringify({ pid: process.pid, label }));
    closeSync(fd);
    return true;
  } catch {
    try {
      const { pid } = JSON.parse(readFileSync(file, "utf8"));
      if (!pidAlive(pid)) {
        unlinkSync(file);
        return tryTake(file, label);
      }
    } catch {
      /* half-written slot: its owner is still writing it */
    }
    return false;
  }
}

export async function acquire(slots: number, label: string, pollMs = 2000): Promise<{ slot: number; release: () => void }> {
  const dir = join(dataDir(), "locks");
  mkdirSync(dir, { recursive: true });
  for (;;) {
    for (let i = 0; i < slots; i++) {
      const file = join(dir, `slot-${i}`);
      if (tryTake(file, label)) {
        return {
          slot: i,
          release: () => {
            try {
              unlinkSync(file);
            } catch {
              /* already gone */
            }
          },
        };
      }
    }
    await new Promise((r) => setTimeout(r, pollMs));
  }
}

export async function lockCommand(argv: string[]): Promise<number> {
  const sep = argv.indexOf("--");
  if (sep < 0 || sep === argv.length - 1) {
    console.error("usage: catherd lock [--slots N] -- <command> [args...]");
    return 2;
  }
  const { values } = parseArgs({ args: argv.slice(0, sep), options: { slots: { type: "string" } } });
  const setting = values.slots ?? process.env.CATHERD_LOCK_SLOTS;
  const [cmd, ...args] = argv.slice(sep + 1) as [string, ...string[]];
  const held = await acquire(heavySlots(setting ? Number(setting) : "cpus/2"), cmd);
  try {
    return await new Promise<number>((resolve) => {
      const child = spawn(cmd, args, { stdio: "inherit" });
      child.on("close", (code) => resolve(code ?? 1));
      child.on("error", () => resolve(127));
    });
  } finally {
    held.release();
  }
}
```
