# catherd 1.x — Plan 8: the Cursor CLI adapter (release 1.1) and the Grok Build adapter (release 1.2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Cursor CLI (`cursor-agent`) as catherd's fifth backend in release 1.1 and Grok Build (`grok`) as its sixth in release 1.2, each through the adapter contract suite, a simulator, synthesized fixtures, live tests gated by `CATHERD_LIVE=1`, catalog entries, discovery, `doctor` rows, profile validation, `capture-fixtures` cases, the docs and one minor changeset.

**Architecture:** Each backend is one folder under `src/adapters/<id>/` (`events.ts` folds the CLI's stream, `models.ts` reads its model listing, `index.ts` is the `BackendAdapter`; grok adds `home.ts` for its isolated `GROK_HOME` and sandbox profiles), registered in `src/adapters/all.ts`. Everything else — `readyAdapter`, `runnableBackends` (profile validation), `doctor`'s backend rows and isolation warning, discovery and `catalog refresh`, `profile show`, `capture-fixtures` — is already derived from the registry (plans 3–5), so registering an adapter is what makes it runnable. Two generic services change: `capture` passes stdin only to a CLI that reads it, and admission enforces the adapter contract's `resume.sameAccessOnly` (declared since plan 1, never checked), which grok needs.

**Tech Stack:** Bun ≥ 1.4 (`bun test`), TypeScript 7 (`tsc --noEmit`), zod 4, citty, oxlint, oxfmt, Changesets. No new dependency. Neither vendor CLI was available while writing this plan: both adapters are built from `docs/research/2026-09-25-cursor-grok.md`, the vendors' documentation it cites, and xAI's model page (fetched 2026-09-26); every guess is a Ruling below and a step of the live-verification kit.

**Spec:** `docs/superpowers/specs/2026-09-25-catherd-1.0-design.md` — D5 (the phased release: "**1.1** = Cursor. **1.2** = Grok. The adapter interface covers all five from day one."), §3.1–3.2 (layers, the adapter interface), §4.3–4.5 (tokens, dispatch, climb and failover), §5.2 (catalog layers, "listed and **disabled** until the user maps it with "treat like""), §6 (common adapter rules), §6.4 (Cursor), §6.5 (Grok Build), §7.1 (validation), §10.3 (`doctor`), §11.2–11.3 and §11.7–11.8 (contract suite, simulators, live tests, fixture capture), §12 (Changesets). Research: `docs/research/2026-09-25-cursor-grok.md` (sections cited as "research §n"). Plans 1–7 (`docs/superpowers/plans/2026-09-2{5,6}-0*.md`) built everything this plan stands on; plans 6 and 7 merge before it runs (see "Re-check needed after plans 6 and 7").

The code below is shown formatted.
- §3.1: "The dependency order, lowest first, is `domain` … → `infra` → `adapters` → `services` → `entry`. A layer imports only from layers below it, and never from the 0.x modules (`src/core`, `src/mcp`, `src/routing`, `src/profile`, `src/tui`, `src/types.ts`)". §3.2: "A backend is one folder under `src/adapters/<id>/` plus its fixtures. No other module names a backend." Register adapters in `src/adapters/all.ts` only.
- §6: "Common to all adapters: brief on stdin (or a file where the CLI cannot read stdin), `cwd` and `PWD` set to the repo, a probe with minimum version, one token convention, a grace kill after the final event." `PWD` comes from `workerEnv`, never from `SpawnPlan.env`.
- §6.4 (Cursor, 1.1): "`agent -p --output-format stream-json --trust --workspace <repo> --model <id> [--resume <chat>]`; each effort is a separate model id from `agent --list-models`; tokens from `result.usage`, no cost; reply is the last `assistant` message; kill after `result` + grace. Access: `read-only` → `--mode ask`, otherwise `--force` with `--sandbox enabled`. Isolation requires a separate `HOME` plus `CURSOR_API_KEY`, because Cursor loads Claude Code hooks and skills; the TUI says so."
- §6.5 (Grok Build, 1.2): "`grok --prompt-file <brief> --output-format streaming-json --cwd <repo> -m <model> --effort <e> --always-approve --trust --no-auto-update -s <uuid>`; resume `-r <id>`. Access → Landlock profiles (`read-only`, `workspace`, `off`) shipped in an isolated `GROK_HOME`; enforcement: enforced where Landlock applies. Limits from the documented messages and code -32003; exit 2 → `cli-too-old`."
- §4.3: "Tokens follow one convention for every backend: `input` includes `cached`." §4.4: "The brief always travels by stdin or file, never argv; positionals follow `--`. The worker env drops `TYPESAFE_API_KEY`, `CATHERD_*` secrets and any `*_API_KEY` catherd itself set, but keeps the user's own backend credentials." Thread ids are checked against the adapter's `threadPattern`; a bad one throws `E_ADMIT_THREAD`.
- §5.2: "A discovered model with no scores is listed and **disabled** until the user maps it with "treat like"." §7.1: `validate` errors on "an unscored rung without a treat-like … a rung whose backend is unknown".
- §10.3: `doctor` checks "each backend (installed, version ≥ min, logged in, discovery ok)" and warns on "`full` access, advisory enforcement and Cursor's weak isolation".
- §11.2: "An adapter ships only when the suite passes." §11.3: simulators for "`codex`, `claude`, `opencode` v2 (then `agent`, `grok`), each with `--version`, login state, model listing, stdin and `$PWD` handling, real error shapes". §11.7: live tests "(`CATHERD_LIVE=1`, owner's machine): one cheap task per backend". §11.8: "`catherd capture-fixtures` records real streams, strips secrets and home paths, and writes `test/fixtures/adapters/<backend>/<cli-version>/`".
- §12: "Releases through Changesets, gated on green CI". **Part A is one PR with one `minor` changeset (1.0.x → 1.1.0); Part B is a second PR with one `minor` changeset (1.1.x → 1.2.0), merged only after the "chore: release catherd" PR that publishes 1.1.0 has merged** — two unreleased minor changesets would publish as a single 1.1.0.
- Tests: an isolated `CATHERD_HOME` per test (`withHome()` or `freshRun()`), `afterEach(snapshotEnv())` in every file that sets an env var, `resetReadiness()` before a test that probes a backend, no network (backend CLIs are the simulators in `test/sim/` or `PATH=/nonexistent`). **A test that spawns a process passes `env` explicitly.** No test waits a fixed time for correctness. Live tests are `describe.skipIf(!process.env.CATHERD_LIVE)`.
- Commits: Conventional Commits, subjects ≤ 100 characters, first word lower-case (commitlint). Never commit a `bun.lock` rewritten by an older Bun. Style: short doc comments only where the why is not obvious.

## Review Focus

1. **Another program named `agent` is on PATH and `cursor-agent` is not** (the research says both names are in use). Expected: catherd does not run it as Cursor; `doctor` says Cursor is missing, with the install command. Task A3 pins it: `test/adapters/cursor.test.ts` "does not take another program named agent for Cursor's CLI".
2. **Cursor prints its `result` and then does not exit** (research §1.7: seen in 2025, and background shells keep `-p` alive). Expected: the supervisor kills it after the grace, and the record is `ok` with the result's reply and tokens, not `failed` for the signal. Task A3 pins it: "is ok once a result arrived, though catherd killed the lingering CLI after it".
3. **A team policy disables `--force`** ("Your team administrator has disabled the 'Run Everything' option"). Expected: `failed` with that message — not `limit`, which would fail over and hit the same policy again. Task A3 pins it in the contract cases ("a team policy that disables --force, which is no limit") and `test/adapters/cursor-events.test.ts` ("tells a usage limit from a team policy").
4. **A fix round resumes a grok session from a role with a different access** (grok fixes a session's sandbox when it creates it and refuses another on resume). Expected: admission refuses it with `E_ADMIT_THREAD` and a fix, before anything is written; the same access resumes. Task B6 pins it: `test/services/admission.test.ts` "refuses to resume a grok session under another access, which grok itself would refuse".
5. **A profile isolates Cursor or grok, but the API key the isolated home needs is not set.** Expected: admission refuses the rung with `E_BACKEND_NOT_LOGGED_IN` and the export command, instead of a run that dies logged out. Tasks A3 ("needs CURSOR_API_KEY to isolate, and makes the isolated HOME") and B3 ("needs XAI_API_KEY to isolate, and writes catherd's sandbox profiles into its GROK_HOME") pin it.

## Rulings on the spec

Each ruling: `Ruling: <what> — <why> — <cost if wrong>`. The live-verification sections that confirm them are §7 (Cursor) and §8 (grok) of `docs/live-verification.md` (Tasks A7 and B8).

**Part A — Cursor**

- **A1.** Ruling: the binary is `cursor-agent`, else `agent`; `probe` accepts it only when `--version` starts with a date (`2026.09.18-9a7762b`) — the installer puts both names on PATH (research §1.1) and `agent` is a generic name another tool may own — cost if wrong: none while both names are installed; a Cursor that drops `cursor-agent` still works as `agent`.
- **A2.** Ruling: `full` access runs `--force --sandbox disabled`; `workspace-write` runs `--force --sandbox enabled`; `read-only` runs `--mode ask` — spec §6.4 says "otherwise `--force` with `--sandbox enabled`", but `full` means no sandbox on every other backend (Codex `danger-full-access`, claude-code `bypassPermissions`), and a verifier or UI reviewer needs the network and paths outside the repo; research §1.4 recommends the same — cost if wrong: one entry of `CURSOR_ACCESS`.
- **A3.** Ruling: Cursor's enforcement is `advisory` for all three access modes — whether `--mode ask` keeps a shell from writing and whether `--force` stays inside the sandbox are unverified (research §1.4, §4.1); under-claiming costs a `doctor` warning, over-claiming costs trust — cost if wrong: once the kit's `sandbox-outside` capture and live test show the sandbox holds, `workspace-write` becomes `enforced` (one value, one test line, one README cell).
- **A4.** Ruling: the catalog runs GPT-6 Astra, Sol, Luna and Claude Fable 5.1, Opus 5.5, Sonnet 5 on Cursor under their canonical ids (`on.cursor.id` = the family id; efforts low…max; context as on the vendor's own CLI), with `sources.cursor` saying so — research §1.5 documents the slug pattern `<canonical id>-<effort>` (`gpt-5.6-sol-xhigh`) but no listing of the owner's account was seen; a Cursor rung then gets its family's price (Cursor bills non-Auto models at API rates) and scores; discovery overrides the efforts, and a wrong id shows as "cursor's last listing does not offer X; routing skips it" — cost if wrong: correct one `id` per family after §7.1 of the kit.
- **A5.** Ruling: logged in is read from `status --format json`: the first boolean among `isAuthenticated`, `authenticated`, `loggedIn`, else the exit code; no JSON at all (an older CLI without `--format`) is `null` (unknown, no problem raised) — the output schema is unverified (research §1.1) — cost if wrong: `loggedInFrom` reads another key.
- **A6.** Ruling: the live tests and capture cases run `cursor:auto#default` — Cursor's own router is the default for new installs and the cheapest thing on a Cursor plan; `auto` has no family, so it is used through `fakeDeps` (live tests) and the capture kit, neither of which validates scores — cost if wrong: the rung string in two files.
- **A7.** Ruling: discovery folds effort-suffixed slugs (`-none`, `-minimal`, `-low`, `-medium`, `-high`, `-xhigh`, `-max`) into one model; its efforts list `default` only when the bare slug is listed too, and `prepare` refuses `#default` otherwise; other suffixes (`-fast`, `-thinking`) stay part of the model id — `#default` means "no effort flag" (spec §5.1), which on Cursor is the bare slug, and research §1.5 says an unmatched effort is unsupported — cost if wrong: a model whose bare slug exists but is unlisted is refused at `#default` with the listed efforts as the fix.
- **A8.** Ruling: the brief goes on stdin with no prompt argument — spec §6 says stdin, and paperclip's production adapter pipes it (research §1.2), though Cursor documents only argv — cost if wrong: the live test's first case fails; the fallback is a positional after `--` that points at the brief file ("Read and follow <briefPath>"), which keeps the brief itself off argv.
- **A9.** Ruling: an isolated Cursor run gets `HOME=<data>/cursor-home` and `XDG_CONFIG_HOME=<data>/cursor-home/.config`, and `prepare` refuses it without `CURSOR_API_KEY` (`E_BACKEND_NOT_LOGGED_IN`); no auth file is linked — spec §6.4 names exactly this pair, and the auth-file paths are unverified (research §1.1, §1.8) — cost if wrong: none for the key path; account-level User Rules still apply (the `doctor` note says so).
- **A10.** Ruling: a run is `ok` when a `result` event without `is_error` arrived, whatever the exit (the grace kill leaves a signal); with no result, `cli-too-old` on commander's "unknown option", `limit` on the research §1.6 texts unless they are a team policy, else `failed`; tokens are `input = inputTokens + cacheReadTokens + cacheWriteTokens`, `cached = cacheReadTokens`, `output = outputTokens`, and `costUsd` is `null` — research §1.2, §1.6, §1.9 (`inputTokens` looks uncached: reads exceed it in the sample) — cost if wrong: `cursorTokens` double-counts the cache; the kit's §7.3 checks it.
- **A11.** Ruling: the minimum version is `2026.09.02` (the first build whose recorded stream carries `result.usage`, research §1.2) and the grace after `result` is 30 s — `extractVersion` reads `2026.09.02` from `2026.09.02-c22c1a3` and compares it numerically — cost if wrong: a newer floor is one constant.
- **A12.** Ruling: the thread is `system/init`'s `session_id`; catherd does not pre-create chats with `agent create-chat` — its output is unverified (research §1.3), and a run that dies before `system/init` has nothing to resume anyway — cost if wrong: none.
- **A13.** Ruling: the written default profile does not gain `cursor`/`grok` billing or harness keys; `resolveProfile` already fills them (`metered`, not isolated), and `profile show` lists them once the backend is runnable — spec §7.1's example writes five billing keys, and init stays unchanged — cost if wrong: two lines in `defaultProfileDoc`.
- **A14.** Ruling: tests that need "a backend with no adapter" unregister `cursor` for the test and put it back (`withoutAdapter`, `test/services/helpers.ts`), and `adapter-hooks.test.ts` restores the real Cursor adapter after each stand-in — they used `cursor` because it had no adapter until 1.1 — cost if wrong: none.

**Part B — Grok Build**

- **B1.** Ruling: the brief goes by `--prompt-file <briefPath>` (`stdinPath: null`), and `capture-fixtures` passes stdin only when the plan asks for it — headless grok "does not read piped stdin" (research §2.2), and spec §6 allows a file "where the CLI cannot read stdin" — cost if wrong: none.
- **B2.** Ruling: access maps to grok's built-in profiles on a native run (`read-only`, `workspace`, `off`) and to catherd's own `catherd-ro`/`catherd-ws` (extending them) on an isolated run, written to `<data>/grok-home/sandbox.toml`, where `catherd-ws` may also write catherd's heavy-lock directory — spec §6.5 says the profiles are "shipped in an isolated `GROK_HOME`"; a built-in profile that cannot be applied runs unenforced with a warning while a custom one refuses to start (research §2.4); catherd does not edit the user's own `~/.grok/sandbox.toml` — cost if wrong: the TOML syntax is the user guide's, unverified; the kit's §8.4 checks it, and a native `workspace-write` worker cannot take the heavy lock (the README says so).
- **B3.** Ruling: an isolated grok run needs `XAI_API_KEY` (`prepare` refuses without it); catherd does not copy or link `~/.grok/auth.json` — a copied OAuth token could spend the user's refresh token, and a linked one may break on refresh (research §2.8) — cost if wrong: a user with only an OAuth login cannot isolate grok.
- **B4.** Ruling: a fresh session gets `-s <uuid>` from catherd; the record's thread is `end.sessionId` (the same uuid), else the request's thread — a failed fresh run (a terminal `error` has no `sessionId`) records no thread — cost if wrong: such a run cannot be resumed, which a failed first turn does not need.
- **B5.** Ruling: a resume passes `-r <id>` and no `--sandbox`, and admission refuses to resume a thread whose last record ran another access (`resume.sameAccessOnly`, generic, `E_ADMIT_THREAD`) — grok refuses a different profile on resume (research §2.3) — cost if wrong: none; isolated-versus-native mismatches are not checked (the session is then "not found" and the run fails with grok's message).
- **B6.** Ruling: the live tests and capture cases run `grok:grok-4.7#low` — the default model at its lowest documented effort — cost if wrong: the rung string in two files.
- **B7.** Ruling: efforts come from a shipped table (`GROK_EFFORTS`: `grok-4.7` → low, medium, high, xhigh, from https://docs.x.ai/developers/grok-4-7); `prepare` refuses an undocumented effort for a model in the table and lets any effort through for other models (grok itself refuses an unsupported one) — `grok models` lists no efforts (research §2.5) — cost if wrong: one table entry.
- **B8.** Ruling: the catalog gains Grok 4.7, 4.6 and 4.5 (vendor `xai`, a new enum value) with xAI's prices under 200K tokens of context and context 500K, image input `false` (undocumented), and **no scores** — no benchmark in the research covers them, and spec §5.2 lists an unscored model disabled until a treat-like maps it; the README shows the command — cost if wrong: a user runs one `catherd catalog treat-like` per rung; scores can ship later as data.
- **B9.** Ruling: a run is `ok` when `end.stopReason` is `end_turn`; with no `end`, exit 2 or clap's "unexpected argument" is `cli-too-old`; an `error` event with code -32003 or a research §2.6 text is `limit`, except "requires a Grok subscription" (`failed`); `max_tokens`, `max_turn_requests`, `refusal`, `cancelled` are `failed` with "stopped: <reason>"; tokens are `end.usage` (`input = input_tokens + cache_read + cache_creation`, `cached = cache_read`, `output = output_tokens`, reasoning assumed inside it since `total_tokens` leaves it out), else the sum of the per-call `usage` events; the live token count sums `usage` events only; `costUsd = end.total_cost_usd ?? null` — research §2.2, §2.6, §2.7 — cost if wrong: one field in `grokTokens`.
- **B10.** Ruling: grok's enforcement is `enforced` for all three modes — spec §6.5 ("enforced where Landlock applies"); `full` has nothing to hold, as on Codex — cost if wrong: on a machine without Landlock or Seatbelt a native run's profile is unenforced; the kit's §8.2 notes it.
- **B11.** Ruling: the minimum version is `1.0.41` (the stable channel when the flags were read, research §0), `GROK_DISABLE_AUTOUPDATER=1` is always set, the grace after `end` or a terminal `error` is 30 s, and every run passes `--trust` (the grant persists) — spec §6.5's argv; a repo's `AGENTS.md` loads only in a trusted folder (research §2.4) — cost if wrong: a floor is one constant.

```ts
import { type Tokens, ZERO_TOKENS } from "../../domain/record.ts";

export interface CursorResult {
  isError: boolean;
  text: string;
  tokens: Tokens;
}

export interface CursorFold {
  thread: string | null;
  /** the text of the last `assistant` event: `result.result` runs every segment together (research §1.2) */
  reply: string | null;
  result: CursorResult | null;
  lastEvent: string | null;
}

/** A usage or rate limit, in stderr or a failed result's text (research §1.6). */
export const CURSOR_LIMIT = [
  /usage limit/i,
  /spend limit/i,
  /rate limit/i,
  /too many requests/i,
  /quota/i,
  /ActionRequiredError/,
  /out of (?:credits|requests)/i,
];
/** A team policy refusal looks like a limit but is not one: it never passes by waiting. */
export const CURSOR_POLICY = [/administrator has disabled/i, /Run Everything/];
/** What an older `cursor-agent` prints for a flag catherd passes (a commander-style error). */
export const CURSOR_TOO_OLD = [/unknown option '--/i, /error: unknown option/i];

type Event = Record<string, any>;

export function parseCursorLine(line: string): Event | null {
  if (!line.trim().startsWith("{")) return null;
  try {
    const e = JSON.parse(line) as unknown;
    return e && typeof e === "object" && !Array.isArray(e) ? (e as Event) : null;
  } catch {
    return null;
  }
}

/**
 * Spec §4.3's convention from `result.usage` (camelCase; research §1.2): `inputTokens` leaves out the
 * cache, so input adds cache reads and writes back.
 */
export function cursorTokens(u: Event | undefined): Tokens {
  if (!u) return { ...ZERO_TOKENS };
  const n = (k: string) => (typeof u[k] === "number" ? (u[k] as number) : 0);
  const cached = n("cacheReadTokens");
  return { input: n("inputTokens") + cached + n("cacheWriteTokens"), cached, output: n("outputTokens") };
}

const textOf = (e: Event): string =>
  ((e.message?.content ?? []) as Event[])
    .filter((c) => c?.type === "text" && typeof c.text === "string")
    .map((c) => c.text as string)
    .join("");

export function eventName(e: Event): string {
  if (e.type === "system") return `system/${e.subtype ?? "?"}`;
  if (e.type === "tool_call") {
    const tool = Object.keys(e.tool_call ?? {})[0] ?? "?";
    return `tool_call/${e.subtype ?? "?"}/${tool}`;
  }
  return String(e.type ?? "?");
}

export const isLimit = (text: string): boolean =>
  CURSOR_LIMIT.some((r) => r.test(text)) && !CURSOR_POLICY.some((r) => r.test(text));

export function foldCursorEvents(lines: string[]): CursorFold {
  const f: CursorFold = { thread: null, reply: null, result: null, lastEvent: null };
  for (const line of lines) {
    const e = parseCursorLine(line);
    if (!e) continue;
    f.lastEvent = eventName(e);
    if (typeof e.session_id === "string" && e.session_id) f.thread ??= e.session_id;
    if (e.type === "assistant") {
      const t = textOf(e);
      if (t) f.reply = t;
    }
    if (e.type === "result")
      f.result = {
        isError: e.is_error === true,
        text: typeof e.result === "string" ? e.result : "",
        tokens: cursorTokens(e.usage),
      };
  }
  return f;
}
```

`src/adapters/cursor/models.ts` (new):

```ts
import type { DiscoveredModel } from "../backend.ts";

/** Effort suffixes Cursor puts on a model's slug (`gpt-6-sol-xhigh`); any other suffix names a model. */
export const CURSOR_EFFORTS = ["none", "minimal", "low", "medium", "high", "xhigh", "max"];

/** The listing may be coloured: ESC `[` … a letter. */
const ANSI = new RegExp(`${String.fromCharCode(27)}\\[[0-9;]*[A-Za-z]`, "g");
const LINE = /^\s*([a-z0-9][a-z0-9._-]*)\s+-\s+\S/;

/** Spec §6.4: each effort is its own slug; `default` is the bare one, with no effort suffix. */
export const cursorSlug = (model: string, effort: string): string =>
  effort === "default" ? model : `${model}-${effort}`;

/**
 * `cursor-agent --list-models` prints `<slug> - <Display Name>` lines under a header (research §1.5).
 * Slugs that differ only by an effort suffix fold into one model; its efforts list `default` when the
 * bare slug is listed too, since only then does a `#default` rung have a slug to run.
 */
export function parseCursorModels(text: string): DiscoveredModel[] {
  const slugs = text
    .replace(ANSI, "")
    .split("\n")
    .map((l) => LINE.exec(l)?.[1])
    .filter((s): s is string => s !== undefined);
  const byModel = new Map<string, Set<string>>();
  for (const slug of slugs) {
    const effort = CURSOR_EFFORTS.find((e) => slug.endsWith(`-${e}`));
    const model = effort ? slug.slice(0, -(effort.length + 1)) : slug;
    const efforts = byModel.get(model) ?? new Set<string>();
    efforts.add(effort ?? "default");
    byModel.set(model, efforts);
  }
  return [...byModel].map(([id, efforts]) => ({
    id,
    efforts: ["default", ...CURSOR_EFFORTS].filter((e) => efforts.has(e)),
    context: null,
    imageIn: false,
  }));
}
```

```ts
#!/usr/bin/env bun
// Cursor CLI simulator for catherd's tests: behaviour comes from the JSON scenario in CATHERD_SIM_CURSOR.
import { mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { dirname, join } from "node:path";

const s = JSON.parse(readFileSync(process.env.CATHERD_SIM_CURSOR ?? "", "utf8")) as Record<string, any>;
const args = process.argv.slice(2);
const say = (text: string) => process.stdout.write(text.endsWith("\n") ? text : `${text}\n`);
const fail = (text: string, code = 1): never => {
  process.stderr.write(`${text}\n`);
  process.exit(code);
};

if (args[0] === "--version" || args[0] === "-v") {
  say(s.version ?? "2026.09.18-9a7762b");
  process.exit(0);
}
if (args[0] === "status" || args[0] === "whoami") {
  const loggedIn = s.loggedIn !== false;
  say(JSON.stringify(loggedIn ? { isAuthenticated: true, email: "sim@cursor.invalid" } : { isAuthenticated: false }));
  process.exit(loggedIn ? 0 : 1);
}
if (args[0] === "--list-models" || args[0] === "models") {
  if (s.modelsFile) process.stdout.write(readFileSync(s.modelsFile, "utf8"));
  process.exit(s.modelsExit ?? 0);
}

const VALUE = ["--output-format", "--model", "--mode", "--sandbox", "--workspace", "--resume", "--api-key"];
const BOOL = ["-p", "--print", "--trust", "--force", "-f", "--yolo", "--approve-mcps"];
const opts: Record<string, string> = {};
const prompt: string[] = [];
for (let i = 0; i < args.length; i++) {
  const a = args[i] as string;
  if (!a.startsWith("-")) {
    prompt.push(a);
    continue;
  }
  if ((s.unknownFlags ?? []).includes(a) || (!VALUE.includes(a) && !BOOL.includes(a)))
    fail(`error: unknown option '${a}'`);
  opts[a] = VALUE.includes(a) ? (args[++i] ?? "") : "true";
}
if (!opts["-p"] && !opts["--print"]) fail("sim: only print mode is simulated", 2);
if (!opts["--trust"] && !opts["--force"] && !opts["--yolo"] && !opts["-f"])
  fail("⚠ Workspace Trust Required\nPass --trust, --yolo, or -f if you trust this directory");

let stdin = "";
try {
  stdin = readFileSync(0, "utf8");
} catch {
  // no stdin
}
const workspace = opts["--workspace"] ?? process.cwd();
writeFileSync(
  s.recordTo,
  JSON.stringify({
    args,
    stdin: [...prompt, stdin].filter(Boolean).join("\n"),
    cwd: process.cwd(),
    pwd: process.env.PWD ?? null,
    xdgConfig: process.env.XDG_CONFIG_HOME ?? null,
    home: process.env.HOME ?? null,
    envKeys: Object.keys(process.env),
  }),
);
const session = opts["--resume"] ?? "00000000-0000-4000-8000-00000000c0de";
setTimeout(async () => {
  for (const t of s.touch ?? []) {
    mkdirSync(dirname(join(workspace, t.path)), { recursive: true });
    writeFileSync(join(workspace, t.path), t.content);
  }
  if (s.eventsFile)
    process.stdout.write(
      readFileSync(s.eventsFile, "utf8")
        .replace(/"session_id":"[^"]*"/g, `"session_id":"${session}"`)
        .replaceAll("<repo>", workspace),
    );
  if (s.stderr) process.stderr.write(s.stderr);
  if (s.hangMs) await Bun.sleep(s.hangMs);
  process.exit(s.exitCode ?? 0);
}, s.delayMs ?? 0);
```

```ts
export function cursorBin(): "cursor-agent" | "agent" {
  return Bun.which("cursor-agent", { PATH: process.env.PATH ?? "" }) ? "cursor-agent" : "agent";

/** Where isolated runs keep their HOME; computing it creates nothing. */

 * every other backend (Ruling A2).

export const CURSOR_ACCESS: Record<Access, string[]> = {
  "read-only": ["--mode", "ask"],
  "workspace-write": ["--force", "--sandbox", "enabled"],
  full: ["--force", "--sandbox", "disabled"],

function plan(r: RunRequest): SpawnPlan {
  if (r.thread !== null && !THREAD.test(r.thread))
    throw new CatherdError("E_ADMIT_THREAD", `"${r.thread}" is not a Cursor chat id`, {
      fix: "pass the thread from the earlier RunRecord",
    });
  const home = isolatedCursorHome();
  return {
    cmd: cursorBin(),
    args: [
      "-p",
      "--output-format",
      "stream-json",
      "--trust",
      "--workspace",
      r.repo,
      "--model",
      cursorSlug(r.rung.model, r.rung.effort),
      ...CURSOR_ACCESS[r.access],
      ...(r.thread === null ? [] : ["--resume", r.thread]),
    ],
    // an empty HOME hides ~/.cursor, ~/.claude, ~/.codex and ~/.agents; CURSOR_API_KEY logs it in
    env: r.isolated ? { HOME: home, XDG_CONFIG_HOME: join(home, ".config") } : {},
    cwd: r.repo,
    stdinPath: r.briefPath,
  };
}

async function listModels(): Promise<DiscoveredModel[]> {
  const r = await runCli(cursorBin(), ["--list-models"], cursorShell);
  return r?.ok ? parseCursorModels(r.out) : [];
}

/**
 * Spec §6.4: an isolated run needs CURSOR_API_KEY (its HOME holds no login), and the rung's slug must be
 * one Cursor lists: the model with that effort suffix, or the bare slug for `#default`.
 */
async function prepare(req: { rung: Rung; access: Access; isolated: boolean }): Promise<void> {
  if (req.isolated) {
    if (!process.env.CURSOR_API_KEY)
      throw new CatherdError("E_BACKEND_NOT_LOGGED_IN", "an isolated Cursor run needs CURSOR_API_KEY", {
        fix: "export CURSOR_API_KEY=<a key from the Cursor dashboard>, or set harness.cursor.isolated false",
      });
    mkdirSync(isolatedCursorHome(), { recursive: true });
  }
  const { model, effort } = req.rung;
  const models = await discovered("cursor", listModels, { maxAgeMs: DAY_MS, need: model });
  if (models.length === 0) return; // Cursor listed nothing: let the run itself say what is wrong
  const m = models.find((x) => x.id === model);
  if (!m)
    throw new CatherdError("E_BACKEND_MODEL_UNKNOWN", `Cursor does not list ${model}`, {
      fix: `run ${cursorBin()} --list-models; a rung names the slug without its effort suffix`,
    });
  if (!m.efforts.includes(effort))
    throw new CatherdError("E_BACKEND_MODEL_UNKNOWN", `Cursor lists no ${cursorSlug(model, effort)}`, {
      fix: `use one of: ${m.efforts.map((e) => `${model}#${e}`).join(", ")}`,
    });
}

function finalize(run: FinishedRun): Outcome {
  const f = foldCursorEvents(run.eventLines);
  const res = f.result;
  const stopped = run.exit.reason;
  const said = [run.stderr, res?.isError ? res.text : ""].join("\n");
  const status: RunStatus =
    stopped === "cancelled"
      ? "cancelled"
      : stopped === "idle-timeout" || stopped === "wall-timeout"
        ? "timeout"
        : res !== null && !res.isError
          ? "ok"
          : res === null && CURSOR_TOO_OLD.some((r) => r.test(run.stderr))
            ? "cli-too-old"
            : isLimit(said)
              ? "limit"
              : "failed";
  const lastErr = run.stderr.trim().split("\n").at(-1) ?? "";
  const message =
    res?.isError && res.text
      ? res.text
      : lastErr || `no result event (${stopped}, exit ${run.exit.code ?? run.exit.signal})`;
  return {
    status,
    thread: f.thread ?? run.request.thread,
    tokens: res?.tokens ?? cursorTokens(undefined),
    costUsd: null,
    images: [],
    error: status === "ok" ? null : { code: status, message },
    ...(status === "ok" ? { reply: f.reply ?? res?.text ?? "" } : {}),
  };
}

function parse(line: string): EventDelta {
  const e = parseCursorLine(line);
  if (!e) return {};
  const d: EventDelta = { lastEvent: eventName(e) };
  if (typeof e.session_id === "string" && e.session_id) d.thread = e.session_id;
  if (e.type === "result") {
    d.final = true;
    d.tokens = cursorTokens(e.usage);
    if (e.is_error === true) {
      d.failure = String(e.result ?? "error");
      if (isLimit(d.failure)) d.limit = true;
    }
  }
  return d;
}

/**
 * Logged in per `status --format json` (research §1.1; its shape is UNVERIFIED, Ruling A5): a boolean
 * `isAuthenticated`, `authenticated` or `loggedIn` when it has one, else the exit code. null when the
 * CLI printed no JSON (an older one without `--format`).
 */
export function loggedInFrom(r: { ok: boolean; out: string } | null): boolean | null {
  const j = jsonOf(r?.out) as Record<string, unknown> | null;
  if (!j || typeof j !== "object") return null;
  for (const k of ["isAuthenticated", "authenticated", "loggedIn"])
    if (typeof j[k] === "boolean") return j[k] as boolean;
  return r?.ok ?? null;
}

async function probe(): Promise<Probe> {
  const bin = cursorBin();
  const v = await runCli(bin, ["--version"], cursorShell);
  if (!v || !CURSOR_VERSION.test(v.out))
    return {
      installed: false,
      version: null,
      versionOk: false,
      loggedIn: null,
      problems: [
        {
          code: "E_BACKEND_MISSING",
          message: v ? `the ${bin} on PATH is not Cursor's CLI` : "cursor-agent is not on PATH",
          fix: CURSOR_INSTALL,
        },
      ],
    };
  const version = extractVersion(v.out);
  const versionOk = version !== null && compareVersions(version, CURSOR_MIN_VERSION) >= 0;
  const loggedIn = loggedInFrom(await runCli(bin, ["status", "--format", "json"], cursorShell));
  const problems: Probe["problems"] = [];
  if (!versionOk)
    problems.push({
      code: "E_BACKEND_TOO_OLD",
      message: `cursor-agent ${version ?? "?"} is older than ${CURSOR_MIN_VERSION}`,
      fix: `${bin} update`,
    });
  if (loggedIn === false)
    problems.push({
      code: "E_BACKEND_NOT_LOGGED_IN",
      message: "cursor-agent is not logged in",
      fix: `${bin} login, or export CURSOR_API_KEY=<key>`,
    });
  return { installed: true, version, versionOk, loggedIn, problems };
}
```

```ts
/** Runs `fn` with `id`'s adapter unregistered, then puts it back: a backend catherd cannot run. */
export async function withoutAdapter<T>(id: string, fn: () => Promise<T>): Promise<T> {
  const a = adapterFor(id);
  unregisterAdapter(id);
  try {
    return await fn();
  } finally {
    if (a) registerAdapter(a);
  }
}
```

```ts
import { type Tokens, ZERO_TOKENS } from "../../domain/record.ts";

export interface GrokEnd {
  stopReason: string;
  thread: string | null;
  tokens: Tokens;
  /** only when the server reported the whole cost (API-key traffic; research §2.2) */
  costUsd: number | null;
}

export interface GrokFold {
  /** the text since the last tool event: the final message (research §2.9) */
  reply: string;
  end: GrokEnd | null;
  /** the terminal `error` event's message: headless prints it instead of `end` */
  error: string | null;
  errorCode: number | null;
  /** the sum of the per-call `usage` events, for a stream with no `end` */
  used: Tokens;
  lastEvent: string | null;
}

/**
 * The rate- and usage-limit texts of `xai-grok-shell/src/sampling/error.rs` (research §2.6); their
 * apostrophes are U+2019, so none of these patterns spells one.
 */
export const GROK_LIMIT = [
  /rate limit/i,
  /usage limit/i,
  /free-usage-exhausted/i,
  /too many requests/i,
  /resource-exhausted/i,
  /at capacity/i,
  /temporarily overloaded/i,
  /purchase more credits/i,
  /try again later/i,
];
/** A plan that lacks Grok Build, which no wait fixes. */
export const GROK_NOT_LIMIT = [/requires a Grok subscription/i];
/** ACP's "Rate limited" error code (research §2.6). */
export const GROK_RATE_LIMITED = -32003;
/** clap's error for a flag this `grok` does not know; its exit code is 2 (research §2.7). */
export const GROK_TOO_OLD = [/unexpected argument '--/i, /unrecognized (?:argument|option)/i];

type Event = Record<string, any>;

export function parseGrokLine(line: string): Event | null {
  if (!line.trim().startsWith("{")) return null;
  try {
    const e = JSON.parse(line) as unknown;
    return e && typeof e === "object" && !Array.isArray(e) ? (e as Event) : null;
  } catch {
    return null;
  }
}

/** Spec §4.3's convention: `input_tokens` is uncached only, so input adds the cache reads and writes. */
export function grokTokens(u: Event | undefined): Tokens {
  if (!u) return { ...ZERO_TOKENS };
  const n = (k: string) => (typeof u[k] === "number" ? (u[k] as number) : 0);
  const cached = n("cache_read_input_tokens");
  return {
    input: n("input_tokens") + cached + n("cache_creation_input_tokens"),
    cached,
    output: n("output_tokens"),
  };
}

export const isGrokLimit = (message: string, code: number | null = null): boolean =>
  !GROK_NOT_LIMIT.some((r) => r.test(message)) &&
  (code === GROK_RATE_LIMITED || GROK_LIMIT.some((r) => r.test(message)));

export function eventName(e: Event): string {
  if (e.type === "tool_call") return `tool_call/${e.toolName ?? e.kind ?? "?"}`;
  if (e.type === "tool_call_update") return `tool_call_update/${e.status ?? "?"}`;
  return String(e.type ?? "?");
}

export function foldGrokEvents(lines: string[]): GrokFold {
  const f: GrokFold = {
    reply: "",
    end: null,
    error: null,
    errorCode: null,
    used: { ...ZERO_TOKENS },
    lastEvent: null,
  };
  for (const line of lines) {
    const e = parseGrokLine(line);
    if (!e) continue;
    f.lastEvent = eventName(e);
    if (e.type === "tool_call" || e.type === "tool_call_update") f.reply = "";
    else if (e.type === "text" && typeof e.data === "string") f.reply += e.data;
    else if (e.type === "usage") {
      const t = grokTokens(e.usage);
      f.used = {
        input: f.used.input + t.input,
        cached: f.used.cached + t.cached,
        output: f.used.output + t.output,
      };
    } else if (e.type === "end")
      f.end = {
        stopReason: String(e.stopReason ?? "?"),
        thread: typeof e.sessionId === "string" && e.sessionId ? e.sessionId : null,
        tokens: e.usage ? grokTokens(e.usage) : f.used,
        costUsd: typeof e.total_cost_usd === "number" ? e.total_cost_usd : null,
      };
    else if (e.type === "error") {
      f.error = String(e.message ?? "error");
      f.errorCode = typeof e.code === "number" ? e.code : null;
    }
  }
  return f;
}
```

`src/adapters/grok/models.ts` (new):

```ts
import type { DiscoveredModel } from "../backend.ts";

/**
 * `grok models` lists no efforts (research §2.5), so they come from xAI's model pages; a model not here
 * lists none, and its effort is left for `grok` itself to accept or refuse.
 */
export const GROK_EFFORTS: Record<string, string[]> = {
  // https://docs.x.ai/developers/grok-4-7: "Low, medium, high (default), or xhigh"
  "grok-4.7": ["low", "medium", "high", "xhigh"],
};

/** xAI's context windows (https://docs.x.ai/developers/models, 2026-09-26). */
const GROK_CONTEXT: Record<string, number> = {
  "grok-4.7": 500_000,
  "grok-4.6": 500_000,
  "grok-4.5": 500_000,
  "grok-build-0.1": 256_000,
};

export interface GrokModels {
  /** null when `grok models` printed none of its three auth lines */
  loggedIn: boolean | null;
  models: DiscoveredModel[];
}

/**
 * `grok models` (src/models.rs): an auth line, `Default model: <id>`, then `Available models:` with
 * `  * <id> (default)` or `  - <id>` lines.
 */
export function parseGrokModels(text: string): GrokModels {
  const loggedIn = /You are (?:using XAI_API_KEY|logged in with)/.test(text)
    ? true
    : /You are not authenticated/.test(text)
      ? false
      : null;
  const at = text.indexOf("Available models:");
  const ids =
    at === -1
      ? []
      : text
          .slice(at)
          .split("\n")
          .map((l) => /^\s*[*-]\s+(\S+)/.exec(l)?.[1])
          .filter((id): id is string => id !== undefined);
  return {
    loggedIn,
    models: ids.map((id) => ({
      id,
      efforts: [...(GROK_EFFORTS[id] ?? [])],
      context: GROK_CONTEXT[id] ?? null,
      imageIn: false,
    })),
  };
}
```

```ts
#!/usr/bin/env bun
// Grok Build CLI simulator for catherd's tests: behaviour comes from the JSON scenario in CATHERD_SIM_GROK.
import { mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { dirname, join } from "node:path";

const s = JSON.parse(readFileSync(process.env.CATHERD_SIM_GROK ?? "", "utf8")) as Record<string, any>;
const args = process.argv.slice(2);
const say = (text: string) => process.stdout.write(text.endsWith("\n") ? text : `${text}\n`);
const fail = (text: string, code = 1): never => {
  process.stderr.write(`${text}\n`);
  process.exit(code);
};
const errorEvent = (message: string): never => {
  say(JSON.stringify({ type: "error", message }));
  process.exit(1);
};

if (args[0] === "--version" || args[0] === "version") {
  say(`grok ${s.version ?? "1.0.41"}`);
  process.exit(0);
}
if (args[0] === "models") {
  const auth =
    s.loggedIn !== false
      ? "You are logged in with auth.x.ai."
      : process.env.XAI_API_KEY
        ? "You are using XAI_API_KEY."
        : "You are not authenticated.";
  const models: string[] = s.models ?? ["grok-4.7"];
  say(auth);
  if (s.loggedIn === false && !process.env.XAI_API_KEY) process.exit(1);
  say(`Default model: ${models[0]}\nAvailable models:`);
  models.forEach((m, i) => say(i === 0 ? `  * ${m} (default)` : `  - ${m}`));
  process.exit(0);
}

const VALUE = ["--prompt-file", "--output-format", "--cwd", "-m", "--effort", "-s", "-r", "--sandbox"];
const BOOL = ["--always-approve", "--yolo", "--trust", "--no-auto-update"];
const opts: Record<string, string> = {};
for (let i = 0; i < args.length; i++) {
  const a = args[i] as string;
  if ((s.unknownFlags ?? []).includes(a) || !(VALUE.includes(a) || BOOL.includes(a)))
    fail(`error: unexpected argument '${a}' found\n\nUsage: grok [OPTIONS]`, 2);
  opts[a] = VALUE.includes(a) ? (args[++i] ?? "") : "true";
}
const promptFile = opts["--prompt-file"];
if (!promptFile) fail("sim: only --prompt-file headless runs are simulated", 2);
const cwd = opts["--cwd"] ?? process.cwd();
writeFileSync(
  s.recordTo,
  JSON.stringify({
    args,
    stdin: readFileSync(promptFile as string, "utf8"),
    cwd: process.cwd(),
    pwd: process.env.PWD ?? null,
    xdgConfig: process.env.XDG_CONFIG_HOME ?? null,
    home: process.env.GROK_HOME ?? null,
    envKeys: Object.keys(process.env),
  }),
);
const efforts: string[] = s.efforts ?? ["low", "medium", "high", "xhigh"];
if (opts["--effort"] && !efforts.includes(opts["--effort"]))
  errorEvent(`Unsupported effort '${opts["--effort"]}' for this model`);
if (opts["-r"] && opts["--sandbox"] && opts["--sandbox"] !== s.sessionSandbox)
  errorEvent("The session's sandbox profile cannot be changed on resume");
if (!opts["-r"] && !opts["-s"]) fail("sim: every simulated run passes -s or -r", 2);
const session = opts["-r"] ?? opts["-s"];
setTimeout(async () => {
  for (const t of s.touch ?? []) {
    mkdirSync(dirname(join(cwd, t.path)), { recursive: true });
    writeFileSync(join(cwd, t.path), t.content);
  }
  if (s.eventsFile)
    process.stdout.write(
      readFileSync(s.eventsFile, "utf8").replace(/"sessionId":"[^"]*"/g, `"sessionId":"${session}"`),
    );
  if (s.stderr) process.stderr.write(s.stderr);
  if (s.hangMs) await Bun.sleep(s.hangMs);
  process.exit(s.exitCode ?? 0);
}, s.delayMs ?? 0);
```

```ts
import { existsSync, mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { join } from "node:path";
import type { Access } from "../../domain/record.ts";
import { dataDir, locksDir } from "../../infra/paths.ts";

/** Where isolated runs keep their GROK_HOME; computing it creates nothing. */
export const isolatedGrokHome = (): string => join(dataDir(), "grok-home");

/**
 * Spec §6.5 access → sandbox profile. A native run uses grok's built-in profiles; an isolated one uses
 * catherd's own, which extend them and refuse to start where Landlock or Seatbelt cannot enforce them
 * (a built-in profile then runs unenforced with a warning; research §2.4).
 */
export const GROK_SANDBOX: Record<"native" | "isolated", Record<Access, string>> = {
  native: { "read-only": "read-only", "workspace-write": "workspace", full: "off" },
  isolated: { "read-only": "catherd-ro", "workspace-write": "catherd-ws", full: "off" },
};

/** The claude and cursor compatibility switches of 26-config-reference.md, all off for an isolated run. */
const COMPAT = ["CLAUDE", "CURSOR"].flatMap((tool) =>
  ["AGENTS", "RULES", "SKILLS", "MCPS", "HOOKS"].map((what) => `GROK_${tool}_${what}_ENABLED`),
);

/** The env of an isolated run: catherd's GROK_HOME, no borrowed Claude or Cursor config, no memory. */
export function isolatedGrokEnv(): Record<string, string> {
  return {
    GROK_HOME: isolatedGrokHome(),
    GROK_MEMORY: "0",
    ...Object.fromEntries(COMPAT.map((k) => [k, "0"])),
  };
}

/** catherd's sandbox profiles; `catherd-ws` may also write the heavy-lock dir, so `catherd lock` works. */
export function sandboxToml(): string {
  return [
    "# Written by catherd: the sandbox profiles of its isolated grok runs.",
    "[profiles.catherd-ro]",
    'extends = "read-only"',
    "",
    "[profiles.catherd-ws]",
    'extends = "workspace"',
    `write = [${JSON.stringify(locksDir())}]`,
    "",
  ].join("\n");
}

/** Writes the isolated GROK_HOME and its sandbox.toml when missing or different. */
export function installGrokHome(): string {
  const home = isolatedGrokHome();
  mkdirSync(home, { recursive: true });
  const file = join(home, "sandbox.toml");
  const text = sandboxToml();
  if (!existsSync(file) || readFileSync(file, "utf8") !== text) writeFileSync(file, text);
  return home;
}
```

```ts
import { CatherdError } from "../../domain/errors.ts";
import type { Rung } from "../../domain/ids.ts";
import type { Access, RunStatus } from "../../domain/record.ts";
import {
  type BackendAdapter,
  compareVersions,
  type DiscoveredModel,
  type EventDelta,
  extractVersion,
  type FinishedRun,
  type Outcome,
  type Probe,
  type RunRequest,
  type SpawnPlan,
} from "../backend.ts";
import { runCli } from "../cli.ts";
import { discovered } from "../discovery.ts";
import {
  eventName,
  foldGrokEvents,
  GROK_LIMIT,
  GROK_TOO_OLD,
  grokTokens,
  isGrokLimit,
  parseGrokLine,
} from "./events.ts";
import { GROK_SANDBOX, installGrokHome, isolatedGrokEnv } from "./home.ts";
import { parseGrokModels } from "./models.ts";

/** The stable channel when the flags were read from its user guide (research §0, §2.2: 1.0.41). */
export const GROK_MIN_VERSION = "1.0.41";
export const GROK_INSTALL = "curl -fsSL https://x.ai/cli/install.sh | bash";
const THREAD = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;
const DAY_MS = 24 * 60 * 60_000;

/** How long a `grok` query (version, models) may take before it counts as failed. */
export const grokShell = { timeoutMs: 15_000 };

function plan(r: RunRequest): SpawnPlan {
  if (r.thread !== null && !THREAD.test(r.thread))
    throw new CatherdError("E_ADMIT_THREAD", `"${r.thread}" is not a grok session id`, {
      fix: "pass the thread from the earlier RunRecord",
    });
  return {
    cmd: "grok",
    args: [
      // headless grok never reads stdin (research §2.2): the brief goes by file
      "--prompt-file",
      r.briefPath,
      "--output-format",
      "streaming-json",
      "--cwd",
      r.repo,
      "-m",
      r.rung.model,
      ...(r.rung.effort === "default" ? [] : ["--effort", r.rung.effort]),
      "--always-approve",
      "--trust",
      "--no-auto-update",
      // a fresh session gets its id from catherd; a resumed one keeps the sandbox it was created with
      ...(r.thread === null
        ? ["-s", crypto.randomUUID(), "--sandbox", GROK_SANDBOX[r.isolated ? "isolated" : "native"][r.access]]
        : ["-r", r.thread]),
    ],
    env: { GROK_DISABLE_AUTOUPDATER: "1", ...(r.isolated ? isolatedGrokEnv() : {}) },
    cwd: r.repo,
    stdinPath: null,
  };
}

async function listModels(): Promise<DiscoveredModel[]> {
  const r = await runCli("grok", ["models"], grokShell);
  return r ? parseGrokModels(r.out).models : [];
}

/**
 * Spec §6.5: an isolated run needs XAI_API_KEY (its GROK_HOME holds no login, and copying the user's
 * OAuth token could spend its refresh; Ruling B3) and catherd's sandbox profiles; the model must be one
 * grok lists, with an effort xAI documents for it when it documents any.
 */
async function prepare(req: { rung: Rung; access: Access; isolated: boolean }): Promise<void> {
  if (req.isolated) {
    if (!process.env.XAI_API_KEY)
      throw new CatherdError("E_BACKEND_NOT_LOGGED_IN", "an isolated grok run needs XAI_API_KEY", {
        fix: "export XAI_API_KEY=<a key from console.x.ai>, or set harness.grok.isolated false",
      });
    installGrokHome();
  }
  const { model, effort } = req.rung;
  const models = await discovered("grok", listModels, { maxAgeMs: DAY_MS, need: model });
  if (models.length === 0) return; // grok listed nothing: let the run itself say what is wrong
  const m = models.find((x) => x.id === model);
  if (!m)
    throw new CatherdError("E_BACKEND_MODEL_UNKNOWN", `grok does not list ${model}`, {
      fix: "run grok models, and use a model it lists",
    });
  if (effort !== "default" && m.efforts.length > 0 && !m.efforts.includes(effort))
    throw new CatherdError("E_BACKEND_MODEL_UNKNOWN", `${model} has no effort "${effort}"`, {
      fix: `use one of: ${["default", ...m.efforts].join(", ")}`,
    });
}

function finalize(run: FinishedRun): Outcome {
  const f = foldGrokEvents(run.eventLines);
  const stopped = run.exit.reason;
  const ended = f.end !== null && f.end.stopReason === "end_turn";
  const status: RunStatus =
    stopped === "cancelled"
      ? "cancelled"
      : stopped === "idle-timeout" || stopped === "wall-timeout"
        ? "timeout"
        : ended
          ? "ok"
          : f.end === null && (run.exit.code === 2 || GROK_TOO_OLD.some((r) => r.test(run.stderr)))
            ? "cli-too-old"
            : isGrokLimit(f.error ?? "", f.errorCode) || (f.error === null && isGrokLimit(run.stderr))
              ? "limit"
              : "failed";
  const errLines = run.stderr.trim().split("\n");
  // clap's usage lines follow its error: the error line says what went wrong
  const lastErr = errLines.find((l) => GROK_TOO_OLD.some((r) => r.test(l))) ?? errLines.at(-1) ?? "";
  const message =
    f.error ??
    (f.end
      ? `stopped: ${f.end.stopReason}`
      : lastErr || `no end event (${stopped}, exit ${run.exit.code ?? run.exit.signal})`);
  return {
    status,
    thread: f.end?.thread ?? run.request.thread,
    tokens: f.end?.tokens ?? f.used,
    costUsd: f.end?.costUsd ?? null,
    images: [],
    error: status === "ok" ? null : { code: status, message },
    ...(status === "ok" ? { reply: f.reply } : {}),
  };
}

function parse(line: string): EventDelta {
  const e = parseGrokLine(line);
  if (!e) return {};
  const d: EventDelta = { lastEvent: eventName(e) };
  // per model call; `end` repeats their sum, so only these count toward the live total
  if (e.type === "usage") d.tokens = grokTokens(e.usage);
  if (e.type === "end") {
    d.final = true;
    if (typeof e.sessionId === "string" && e.sessionId) d.thread = e.sessionId;
    if (typeof e.total_cost_usd === "number") d.costUsd = e.total_cost_usd;
    if (e.stopReason !== "end_turn") d.failure = `stopped: ${e.stopReason}`;
  }
  if (e.type === "error") {
    d.final = true;
    d.failure = String(e.message ?? "error");
    if (isGrokLimit(d.failure, typeof e.code === "number" ? e.code : null)) d.limit = true;
  }
  return d;
}

async function probe(): Promise<Probe> {
  const v = await runCli("grok", ["--version"], grokShell);
  if (!v)
    return {
      installed: false,
      version: null,
      versionOk: false,
      loggedIn: null,
      problems: [{ code: "E_BACKEND_MISSING", message: "grok is not on PATH", fix: GROK_INSTALL }],
    };
  const version = extractVersion(v.out);
  const versionOk = version !== null && compareVersions(version, GROK_MIN_VERSION) >= 0;
  // grok has no status command; `grok models` starts with the auth line (research §2.1)
  const models = await runCli("grok", ["models"], grokShell);
  const loggedIn = models ? parseGrokModels(`${models.out}\n${models.err}`).loggedIn : null;
  const problems: Probe["problems"] = [];
  if (!versionOk)
    problems.push({
      code: "E_BACKEND_TOO_OLD",
      message: `grok ${version ?? "?"} is older than ${GROK_MIN_VERSION}`,
      fix: "grok update --stable",
    });
  if (loggedIn === false)
    problems.push({
      code: "E_BACKEND_NOT_LOGGED_IN",
      message: "grok is not logged in",
      fix: "grok login (or grok login --device-auth without a browser), or export XAI_API_KEY=<key>",
    });
  return { installed: true, version, versionOk, loggedIn, problems };
}

export const grokAdapter: BackendAdapter = {
  id: "grok",
  minVersion: GROK_MIN_VERSION,
  probe,
  listModels: () => listModels(),
  prepare,
  plan,
  parse,
  finalize,
  // spec §6.5: Landlock (Linux) or Seatbelt (macOS) holds each profile; `full` runs with the sandbox off
  enforcement: { "read-only": "enforced", "workspace-write": "enforced", full: "enforced" },
  errors: { limit: GROK_LIMIT, tooOld: GROK_TOO_OLD },
  // a session keeps the sandbox it was created with; another is refused (research §2.3)
  resume: { supported: true, sameAccessOnly: true, threadPattern: THREAD },
  // headless drains background tasks for up to 120 s after its final event (research §2.7)
  graceAfterFinalMs: 30_000,
};
```
