# TUI frames

Generated by rendering each screen through `@opentui/react/test-utils`'s `testRender`, at 80x24
and 120x40, in normal and `--plain`. For eyeballing only — not a golden-file test; the real gate is
`bun test`.

Colour is the one thing a plain-text dump cannot show: the ginger-to-pink wordmark gradient, the
pink accent on headings and the selected row's filled bar, and the green/amber/red status dots all
render as plain text here. `test/tui/theme.test.ts` checks `tint()`/`dotTint()`'s hex output, and a
manual pty run (`bun src/cli.ts`) shows the real ANSI codes.
