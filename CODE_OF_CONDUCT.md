# Code of Conduct

catherd follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in every project space (issues, pull requests, discussions and reviews) and when someone represents the
project elsewhere.

In short: be welcoming and respectful, give and take feedback constructively, and focus on what is best for the
people using and building catherd. Harassment, insults, and publishing others' private information are not
acceptable.

## Reporting

Report unacceptable behaviour to the maintainer, [@47vigen](https://github.com/47vigen), privately through GitHub
(for example by asking for a private contact in an issue without details, or through the contact on the
maintainer's profile). Every report is reviewed and handled confidentially, and the maintainer applies the
Covenant's enforcement guidelines: correction, warning, temporary ban or permanent ban.
