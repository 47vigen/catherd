Fixes from a full review of the 2.0 line. Roles can write only `plan.md`, `dossier.md` and lane files, so a read-only role can no longer forge run events or write into milestone worktrees. The panel token works once, and panel sessions expire when idle. A refused judge is started again, and an owner's answer reaches the next brief. The daemon stops when it cannot record a failed effect, and it settles each dispatch only once. The unit-context cap is enforced in bytes, and plan headings inside code fences no longer cut tasks. A 1.5 profile with Jev off is no longer moved onto TypeSafe. The live run page keeps its socket open after a failed read.
