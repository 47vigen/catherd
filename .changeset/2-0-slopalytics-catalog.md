Part of 2.0.0. The catalog reads only the Slopalytics index: one intelligence per model and effort, refreshed hourly. Every benchmark source, `scores.json`, the Artificial Analysis key, treat-likes and `catalog.override.json` are gone; a pair without an index is not offered and fails `profile validate`; bars are intelligence percentiles; a run pins the index it started on and refuses to start when a role has no usable rung. The Grok Build and Antigravity backends are removed.
